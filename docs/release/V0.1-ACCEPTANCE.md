# CineWeave V0.1 发布验收记录模板

本文件是仓库内受版本控制的验收模板，记录同一份 Windows x86_64 候选包需要具备的自动证据与断网人工体验。最终验收时，把本文件复制到工作树之外并命名为 `CineWeave-v0.1.0-ACCEPTANCE.md`；填入准确的源码提交、哈希和结果后，作为 GitHub Release 资产发布并链接到 Issue #12，完成件不提交回仓库。这样填写验收结果不会产生一个新提交并使已经验收的候选包 `source_commit` 失效。

只有外部完成件的所有必填项都有可追溯结果时，才允许让 `v0.1.0` 标签指向该源码提交并发布 GitHub Release。本模板保留 `PENDING` 是正常状态，不代表已发布版本的验收结论。
